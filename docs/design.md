# design.md

## 解決する問題

ティラノスクリプトの書式入力によって、シナリオを考える流れが中断される問題。

作者はシナリオ（セリフ、地の文、展開、分岐）を考えたいのに、タグの記法や素材指定の書式を思い出す作業が挟まり、思考が途切れる。

## 解決方法

作者は音声でシナリオを語り、文字起こし結果をClaude Code Skillがティラノスクリプトへ変換する。

独自エンジンや独自記法は作らない。実行はティラノスクリプトにそのまま任せる。

## 設計上の中心

```text
人間は語る
AIは変換する
ティラノは実行する
```

- 人間（作者）だけがシナリオの内容を決める
- AI（Skill）は語られた内容をティラノスクリプトの記法へ写す。創作・推敲・補完はしない
- ティラノスクリプトが唯一の実行基盤。ランタイムを再発明しない

## 正本

初期段階では、音声文字起こしテキストと生成された`.ks`のどちらを正本とするかを固定しない。

- 音声文字起こしは入力の記録であり、最終的な編集は`.ks`で行う可能性が高い
- 本ツールは初稿生成を主目的とするため、生成後の`.ks`を人間が直接編集する運用を許容する
- したがって、**再生成によって手修正を上書きする設計にはしない**。出力先に既存の`.ks`がある場合、Skillは上書き前に確認する

## 制約

- 自然言語の意図は完全には復元できない
- 入力は音声認識の誤りを含む
- 細かな局所編集は文字入力の方が速い（本ツールは初稿生成に向き、微修正には向かない）
- 一発で完成品を作るものではない
- AIの解釈結果は作者による確認を必要とする
